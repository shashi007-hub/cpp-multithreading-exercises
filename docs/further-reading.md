# Further Reading

## Books
- Anthony Williams, *C++ Concurrency in Action* (2nd ed.)
- Herlihy and Shavit, *The Art of Multiprocessor Programming*
- Paul McKenney, *Is Parallel Programming Hard, And, If So, What Can You Do About It?* (free online)
- Brian Goetz et al., *Java Concurrency in Practice* (the principles transfer directly)

## Talks and articles
- Herb Sutter, "Effective Concurrency" column and "atomic<> Weapons" talk
- Fedor Pikus, CppCon talks on lock-free programming and memory models
- Preshing on Programming, memory ordering series
- Dmitry Vyukov, 1024cores (lock-free algorithms)

## Reference
- cppreference.com: Concurrency support library, memory model
- The C++ standard: [intro.multithread] and [thread]
